# Crista — Product Truth

## What it is

Геймифицированный travel-суперапп на русском языке. Не «ещё один планировщик маршрутов»:
одна поездка сегодня склеена вручную из 5–6 несвязанных приложений (разговорник, википутеводитель,
делёж расходов, агрегатор билетов, городской квест, OTA). Crista — единственное место, где эти
данные образуют одну непрерывную историю. Это и есть защита от копирования одной фичей.

## Who it's for

Русскоязычные путешественники, для которых поездка — это не только логистика, но и прогресс:
хотят открывать мир как игру, вести личный архив поездок, соревноваться с друзьями, копить на цель.
Пилотные города: Москва, Санкт-Петербург, Сочи.

## Core jobs

1. **Спланировать** — сгенерировать и обсудить маршрут с AI, уложиться в бюджет, учесть сезон и интересы.
2. **Открывать мир как игру** — карта с туманом войны, квесты, фокус страны, стрики, штампы.
3. **Копить на поездку** — копилка с целью из живого ценообразования, push при падении цены.
4. **Помнить и показать** — тревел-паспорт, мини-сайты поездок, облачная галерея, годовой Wrapped.
5. **Соревноваться и делиться** — друзья, лидерборды, «гонки» за страну, маршруты звёзд и блогеров.

## Structure (5 разделов)

| Раздел | Задача пользователя |
|---|---|
| **Маршрут** | Чат с AI: сгенерировать/обсудить маршрут, увидеть места на карте |
| **Игра** | Карта мира с туманом войны → страна → точки квестов; фокус страны, копилка |
| **Wiki** | Справочник по странам: история, кухня, традиции, виза, разговорник |
| **Сообщество** | Лента друзей, лидерборды, чужие маршруты, «гонки» |
| **Путешествия** | Тревел-паспорт со штампами, «Мои путешествия», галерея, Wrapped |

Вне навигации: онбординг (бэкфилл «где уже был» + первый квест ~60 сек), auth,
модалки (подписка/оплата/сохранение маршрута/анти-чит фото), публичный мини-сайт поездки.

## Non-negotiables

- **Весь UI на русском.** Кириллица — не опция, а требование к каждому шрифту.
- **Тёмная тема — флагман.** Светлая существует, но продукт продаётся тёмным.
- **Frontend-only.** Все данные — моки из `src/mocks/`, никакого бэкенда.
- **TypeScript strict, без `any`.** Никаких `.js`/`.jsx` файлов.
- **Без новых UI-библиотек и стейт-менеджеров.** Radix + CVA + единственный React Context.

## Monetization

Премиум-тир: заморозка стрика, премиальные квесты, расширенный объём облачной галереи,
партнёрские букинги. Гость → зарегистрированный → подписчик.

## Stage

Фаза 0–1: контент и прогресс для пилотных городов, фокус страны, главный экран, Wiki.
Живое ценообразование, копилка, паспорт — фаза 2. Социальный слой и Wrapped — фаза 3.
