# Crista — Дизайн-бриф

> Источник для скилла `design` (Claude Design canvas). Синтез 10 референсов-скриншотов +
> продуктового докса `Crista_ФИНАЛ_для_разработки.docx` + текущего кода репозитория +
> реальных данных дизайн-галереи a1 (медианы радиусов/типографики/эффектов по индустрии).

## 0. Продукт (контекст, не токены)

Crista — не просто чат-планировщик поездок, а геймифицированный travel-суперапп на русском языке:
карта мира с «туманом войны» (аналог Genshin Impact), квесты и стрики, фокус страны
(ежедневный + еженедельный трек), финансовая копилка под цель, тревел-паспорт со штампами,
сообщество/лидерборды, Crista Wiki, «звёздные» маршруты, генератор мини-сайтов поездок,
облачная галерея, Crista Wrapped.

Стек: React 18 + TypeScript (strict) + Tailwind (`darkMode: 'class'`) + shadcn/ui (Radix + CVA) +
Framer Motion + React Router v6 + Leaflet/React-Leaflet + Three.js/R3F. Frontend-only, мок-данные.

## 1. Направление и стиль

**Фиолетово-синий glassmorphism, сквозной паттерн по всему интерфейсу** (не только карточки —
сайдбар, панели, модалки, поверхности игры). Референс по духу: Saint Petersburg/Doha Explorer
скриншоты (стеклянные панели поверх атмосферного фото/градиента).

Живой ориентир из индустрии (a1 gallery, hero-секции dark SaaS/AI-продуктов, n=312):
- heading size медиана **64px** (p25 50 / p75 80)
- radius медиана **12px** (p25 8 / p75 20)
- эффекты: border 42% сайтов, gradient 29%, shadow 27%, backdrop-blur только 16% —
  **blur — акцент на приподнятых поверхностях, а не тотальный фон**
- ближайший живой аналог по духу: **Better Stack** (`#0b0c14` фон, radius 12, border+shadow+
  gradient+blur вместе, холодная тёмно-синяя гамма) — ориентир для «глубины» тёмной темы.

## 2. Цвет

**Двухцветная система:**
- **Бренд/CTA-акцент** — тил из текущего лого/manifest: `#3BA8B8` (градиент лого: `#5BC4F7 →
  #3BA8B8 → #1A8A9C`). Не меняем — узнаваемость Crista. Используется на первичных кнопках,
  активных состояниях nav, прогресс-барах, значках.
- **Glass-атмосфера** — фиолетово-синяя: холодные тёмно-фиолетовые/индиговые поверхности,
  подсветка, тени стеклянных панелей. Ориентировочная база (уточнить оттенки в canvas):
  фон `#0B0A17 → #14101F`, поверхности `#1C1730` / `#241D3D`, подсветка/glow `#6B5BFF`–`#8B7CFF`.

**⚠️ Известный баг в коде, который новая система должна закрыть:** сейчас
`--color-primary` в `src/index.css` = `#10a37f` (зелёный), а лого/manifest используют `#3BA8B8`
(тил) — расхождение, унифицировать на тил при переносе токенов.

### Темы
- **Тёмная — флагман**: полный glass-язык, все эффекты активны.
- **Светлая — упрощённый fallback**: те же компоненты и те же цветовые роли (bg/surface/text/
  accent), но без демонстрации отдельного стиля — просто светлые значения токенов, blur
  сокращён или убран (снижение уместности glass на светлом фоне + перф).

## 3. Типографика

Три роли, все с полноценной кириллицей:

| Роль | Шрифт | Где |
|---|---|---|
| Display / hero | **Cormorant Garamond** | крупные заголовки, названия стран/городов, hero-текст, эмоциональные акценты |
| Акцент / подзаголовок | **Old Standard TT** | подзаголовки, цитаты, вводные абзацы Wiki-статей, штампы паспорта |
| UI / функциональный текст | **Golos UI** (ParaType, Google Fonts, бесплатный, спроектирован под кириллицу) | кнопки, чат, лейблы, карточки, формы, навигация — весь интерфейс |

Decorative-варианты (Nautilus Pompilius, Rosarium) — **рассмотрены и отклонены**: оба
чисто декоративные (рукописный/цветочный), непригодны для UI, не включаем в систему.

Шкала (ориентир по индустрии, hero median 64 / features median 48):
`display 64–80px` · `h1 48px` · `h2 32px` · `h3 24px` · `body 16px` · `small 14px` · `caption 12px`.

## 4. Информационная архитектура

Полностью переосмыслена под реальный продукт (текущий роутинг `/`, `/login`, `/signup` —
не сохраняем, это MVP-заглушка).

```
Header (persistent): лого · переключатель RU/EN · уведомления · аватар → настройки/выход

Primary nav — 5 разделов:
 1. МАРШРУТ      — чат-планировщик (текущий чат-MVP), генерация/обсуждение маршрута
 2. ИГРА         — карта мира с туманом войны → карта страны/города → точки квестов,
                    фокус страны (ежедневный + еженедельный трек), копилка
 3. WIKI         — справочник по странам/городам
 4. СООБЩЕСТВО   — лента друзей, лидерборды, маршруты других пользователей, «гонки»
 5. ПУТЕШЕСТВИЯ  — тревел-паспорт со штампами, «Мои путешествия» (сетка карточек поездок /
                    мини-сайтов), облачная галерея, Crista Wrapped

Вне nav:
 · Онбординг (бэкфилл «где уже был» + первый квест ~60 сек)
 · Auth (login / signup)
 · Модалки: подписка/оплата, сохранение маршрута, анти-чит фото-подтверждение точки
 · Публичная страница мини-сайта поездки — отдельный лёгкий шаблон, без основного nav,
   заточен под шеринг/SEO
 · Админка (раздел 8.1 продуктового докса) — сознательно вне этого брифа: внутренний
   инструмент, другая аудитория и приоритеты
```

Home (`/`) = хаб, не сразу чат: точка входа с быстрым доступом ко всем 5 разделам.

## 5. Глубина проработки по экранам

| Уровень | Экраны |
|---|---|
| **Полный макет + состояния** | Home-хаб, Маршрут (чат), Игра (карта мира + фокус страны + копилка), Путешествия (паспорт + Мои путешествия + галерея + Wrapped) |
| **Паттерны компонентов** | Wiki (статья), Сообщество (лента/лидерборды) |
| **Токены + один референс-макет** | Онбординг, Auth, модалки, публичный мини-сайт |
| **Вне брифа** | Админка |

## 6. Игра — визуальное единство

Единая система токенов на весь продукт (не отдельная палитра для игрового слоя), но с более
выразительными game-specific компонентами внутри: пульсирующий туман войны, анимированные
пины квестов, bounce-анимация при открытии страны, конфетти при закрытии фокуса на 100%,
бейджи тиров. Геймификация считывается за счёт анимации/свечения/иконографии, а не за счёт смены
всей визуальной системы.

## 7. Изображения

- **Wiki, места, обложки поездок, карточки в «Путешествиях»**: кинематографичная фотография
  (AI-generated или редакционная — источник не важен, важна обработка) — тёплый golden-hour
  свет, лёгкая desaturation теней под тёмную тему. Референс: Doha/Saint Petersburg Explorer,
  Rome Explorer скриншоты.
- **Карта мира в «Игре»**: отдельный **иллюстративный/painted слой**, не фотореализм — карта с
  туманом войны и пинами поверх фото плохо читается; нужна стилизованная низкодетализированная
  подложка, которая не спорит с UI-слоем сверху.

## 8. Системные токены

**Radius**: `sm 8px` (инпуты, чипы) · `md 12px` (кнопки, мелкие карточки) · `lg 20px` (PlaceCard,
панели) · `xl 28px` (модалки, крупные glass-контейнеры) · `full` (аватары, pill-бейджи, круглые
CTA в игре).

**Spacing**: база `4px`, шкала `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`.

**Glass-рецепт** (единый для всех стеклянных поверхностей):
```
background: rgba(surface, 0.55–0.65)
backdrop-filter: blur(20px)
border: 1px solid rgba(255,255,255,0.08)
box-shadow: 0 8px 32px rgba(brand-purple, 0.25)
```
На мобильных и в длинных списках (чат, карта игры) — понижать blur до `12px` или отключать
полностью ради перформанса.

**Motion** (Framer Motion): базовая сдержанная анимация `150–250ms` fade/slide на большей части
интерфейса; более «живая»/игровая анимация (пульс тумана, bounce, конфетти) — только в разделе
ИГРА.

**Иконки**: `lucide-react` остаётся базовым набором (уже в коде); добавляется отдельный
кастомный набор мелких game/badge-иконок (штампы, тир-бейджи) поверх него — не замена всей
иконосистемы.

## 9. Известные технические долги для учёта при переносе токенов

- `tailwind.config.js` не содержит `borderRadius` / `boxShadow` / `spacing`-расширений — сейчас
  radius расставлен ad hoc (`rounded-lg/xl/2xl/full` вперемешку) — новая система должна ввести
  единую шкалу токенов.
- `tailwindcss-animate` используется в `dialog.tsx` (`data-[state=open]:animate-in` и т.д.), но
  плагин не зарегистрирован в `plugins: []` — проверить/починить при внедрении.
- Единственный шрифт сейчас — Inter через Google Fonts `<link>`; заменить/дополнить связкой
  Cormorant Garamond + Old Standard TT + Golos UI, тоже через Google Fonts (все три там есть).

## 10. QC — anti-pattern проверка перед сдачей

При генерации самой системы в скилле `design` (Claude Design canvas) — обязательно прогонять
результат через уже установленные в проекте skills:

- **`design-taste-frontend`** (taste-skill v2, anti-slop чек-лист: инференс брифа, никаких
  generic AIDA-шаблонов, никаких дешёвых meta-labels типа «SECTION 01», реальная асимметрия и
  motion только там, где оправданы) — как pre-flight фильтр перед финализацией любого экрана.
- **`impeccable`** — UX-аудит: визуальная иерархия, cognitive load, accessibility, anti-patterns,
  theming (свет/тьма должны быть согласованы), responsive-поведение.

Не одноразовая сверка в конце, а чек на каждый значимый экран (Home-хаб, Маршрут, Игра,
Путешествия) перед тем, как считать его готовым.
