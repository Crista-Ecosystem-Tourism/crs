# Crista — Design System

> Committed visual world. Tokens live in `tailwind.config.js` + `src/index.css`.
> Source: Crista Design System (claude.ai/design) + reference moodboard.

## The world in one line

**Ночной полёт над освещённым городом**: кинематографичное фото как земля, стеклянные панели
как воздух над ней, тил как единственный свет, который принадлежит Crista.

## Anti-reference

Что этот продукт **не** делает, даже если так проще:
- Не плоский тёмно-серый дашборд с карточками `bg-surface` — это дефолт любого SaaS.
- Не «Inter 16px на #171717». Дефолтный системный вид — провал брифа.
- Не фиолетовый градиент-в-лоб. Фиолетовый — атмосфера и тень, не заливка кнопок.
- Не иконка-в-кружочке-с-подписью как основной способ показать раздел.

## Ground: photography

Фотография — **основа композиции, а не украшение**. Каждый крупный экран стоит на снимке.
- Обработка: golden hour / синий час, тёплые огни, глубокие холодные тени.
- Фото всегда под слоем: `linear-gradient(to top, ink-950 0%, ink-950/20 55%, transparent 100%)`,
  иначе текст поверх нечитаем.
- Крупные фоны — приглушены (`opacity .5–.7` + blur), карточные фото — в полную силу.
- Никогда не растягивать: `object-cover`, фиксированный aspect-ratio.

## Air: glass

Стекло — способ положить интерфейс поверх фото, не закрывая его.

```
.glass          → панели поверх тёмного фона   (blur 24px, bg .5, border white/.10)
.glass-on-photo → панели прямо поверх снимка   (blur 32px + saturate, border white/.16)
```

Правила:
- **Верхняя кромка светится.** Каждая стеклянная панель несёт `border-top` светлее остальных
  граней — так стекло читается как физический объект, а не как прозрачный div.
- Стекло **не вкладывается в стекло**. Внутри панели — плоские поверхности `bg-white/5`.
- В длинных списках (чат, лента, карта) blur снимается: только `bg` + `border`. Перф важнее.

## Light: colour

| Роль | Токен | Где |
|---|---|---|
| Бренд, действие | `teal-500 #3BA8B8` → `teal-400` hover | Основные CTA, активный пункт nav, прогресс |
| Атмосфера | `violet-glow-500 #6B5BFF` | Свечения, тени панелей, фокус-кольцо, туман в Игре |
| Земля | `ink-950 #0B0A17` → `ink-900` | Фон, градиент страницы |
| Текст | `#F4F2FB` / `#B8B3CC` / `#7A7593` | primary / secondary / muted |

Тил — **редкий**. Если на экране больше трёх тиловых пятен, это уже не акцент.
Оранжевый/золотой из референсов — только для игровых наград (штампы, тиры), не для UI.

## Type

| Роль | Шрифт | Размер |
|---|---|---|
| Display | **Cormorant Garamond** | 48–80px, `tracking-tight`, `leading-[1.05]` |
| Accent | **Old Standard TT** | 18–24px, подзаголовки, цитаты Wiki, штампы |
| UI | **Golos Text** | 12–18px, всё функциональное |

- Названия городов и стран — **всегда** display serif. Это подпись Crista.
- Serif никогда не опускается ниже 24px и никогда не появляется в кнопке или лейбле.
- Golos Text никогда не появляется в display-размере — крупный гротеск читается как дефолт.

## Shape & depth

- Radius: `sm 8` инпуты/чипы · `md 12` кнопки · `lg 20` карточки/панели · `xl 28` модалки · `full` пилюли, аватары, круглые кнопки.
- Круглая иконочная кнопка (`rounded-full`, 40–44px) — фирменный элемент из референсов:
  избранное, навигация, «развернуть». Не квадратная.
- Тени — только на поднятых поверхностях, и всегда с фиолетовым подмесом, не чёрные.

## Motion

- Интерфейс: 150–250ms, `ease-standard`. Появление панелей — fade + 8px подъём, не scale.
- Игра: разрешено больше — пульс тумана 2400ms, `bounce-in` на открытии страны, конфетти на 100%.
- Фото: `scale(1.06)` за 700ms на hover карточки. Единственная «дорогая» анимация в списках.
- `prefers-reduced-motion` снимает всё, кроме opacity.

## Layout

- Левый **icon rail** (72px) — постоянная навигация по 5 разделам, раскрывается в 280px панель.
- Контент — `max-w-[1320px]`, дышит: 32–48px паддинги секций на десктопе, 16–20px на мобиле.
- Правая колонка-список с миниатюрами (как «Must-See Destinations» в референсе) — повторяющийся
  паттерн: 56×56 фото, заголовок, подпись, локация, круглая кнопка действия справа.
- Мобильный: rail уезжает в нижний таб-бар, правые колонки уходят под основной контент.

## Component vocabulary

| Компонент | Роль |
|---|---|
| `GlassPanel` | Базовая стеклянная поверхность, варианты `panel` / `on-photo` / `flat` |
| `HeroCanvas` | Фото + градиент + контент поверх — основа каждого крупного экрана |
| `PlaceCard` | Фото 4:3, теговая пилюля, display-название, локация, круглая кнопка |
| `ListRow` | Миниатюра 56×56 + текст + круглая кнопка — правые колонки |
| `StatTile` | Мини-карточка «погода/дни/бюджет»: иконка, крупное число, подпись |
| `Chip` | Пилюля-фильтр/тег, `rounded-full`, 12px UI-шрифт uppercase tracking-wide |
| `IconButton` | Круглая 40px, `bg-white/10`, hover → `bg-white/16` |
| `SectionHeading` | Display serif + «Смотреть все →» справа |

## Quality floor

- Контраст текста на фото проверяется на самом светлом кадре, не на самом тёмном.
- Каждое фото — с `alt`, каждая иконочная кнопка — с `aria-label`.
- Фокус виден всегда: `ring-2 ring-glow` поверх стекла, не `outline: none`.
- Пустые состояния и загрузка проектируются вместе с наполненным видом, не после.
