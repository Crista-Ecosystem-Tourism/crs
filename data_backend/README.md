## CI/CD

После появления кода push в `main` копирует репо в [crs/data_backend](https://github.com/Crista-Ecosystem-Tourism/crs) — см. [инструкцию](https://github.com/Crista-Ecosystem-Tourism/crs/blob/main/docs/CI-CD-SYNC.md) и секрет `CRS_SYNC_PAT`. Сборка в Docker Compose — когда добавите сервис в `crs/docker-compose.yml`.
